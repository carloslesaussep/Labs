An RDD (Resilient Distributed Dataset) is the fundamental data structure of Apache Spark—a fault-tolerant collection of data elements that can be processed in parallel.
-Resilient: Fault-tolerant; if data is lost, it can be automatically recomputed using its lineage history.
-Distributed: Data is split into partitions and stored across multiple nodes in a cluster.
-Dataset: A collection of partitioned data elements (can be structured or unstructured).
